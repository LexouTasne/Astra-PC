# Desktop UI attribution

Astra Desktop is an original Electron + React interface for Astra-PC.

Its desktop-shell direction was informed by the MIT-licensed Hermes Agent desktop application:

- Project: NousResearch/hermes-agent
- Desktop source: apps/desktop
- License: MIT
- Copyright (c) 2025 Nous Research

Astra does not vendor Hermes' full desktop source or dependency graph. The Astra shell was rewritten for Astra's local daemon, voice, gestures, Mesh and setup workflows.

The Hermes MIT license permits use, modification and distribution provided the copyright and permission notice are preserved for copied/substantial portions.
